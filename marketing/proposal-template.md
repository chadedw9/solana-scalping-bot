# Upwork Proposal Templates

> Golden rules for proposals (this is where most beginners lose):
> 1. **First line must NOT be generic.** Reference their specific project. Upwork
>    only shows the first ~2 lines in the preview — hook them there.
> 2. **Prove you read it** by restating their goal in your own words.
> 3. **Show, don't tell** — link the demo bot / repo.
> 4. **End with one easy question** to start a conversation.
> 5. Keep it short. 5–8 lines beats a wall of text.
> 6. Apply fast — being in the first 5 applicants matters a lot.

---

## Template A — Crypto / Telegram bot jobs

```
Hi [Name] — a Solana price-alert Telegram bot is almost exactly what I built
last week, so I can move fast on this.

Quick read-back to make sure I've got it: you want [restate their goal in 1
sentence — e.g. "a bot that DMs you when a token you pick goes above/below a
price"]. That's very doable.

Here's a working demo you can try right now: [DEMO BOT LINK]
And the source, so you can see how I write code: [GITHUB REPO LINK]

I'd build this in Python with clean, documented code you'll own, using free
price data (no monthly API bills). I can have a first working version to you in
[X days].

One question so I scope it right: do you want this for a single token/wallet, or
should it handle many at once?

Thanks!
[Your name]
```

## Template B — Bug fix / small automation jobs

```
Hi [Name] — I can fix this. From your description it sounds like [restate the
problem briefly], which is the kind of thing I turn around quickly.

If you can share the code/error (or a sample of the data), I'll confirm the fix
and give you an exact timeline before you commit anything.

Recent related work + how I write code: [GITHUB REPO LINK]

I can usually get small fixes done within [1–2 days]. What does a "done" result
look like for you?

[Your name]
```

## Template C — AI chatbot jobs

```
Hi [Name] — I build custom AI chatbots and this fits well. You're looking for
[restate: e.g. "a support bot trained on your FAQs that answers customers 24/7"].

I'd connect it to [their platform — website/Telegram/etc.], train it on your
content, and add a clean handoff to a human when the bot isn't sure.

Sample of my work: [GITHUB / PORTFOLIO LINK]

To give you an accurate quote: roughly how many FAQ/doc pages should it learn
from, and where do you want it to live (website, Telegram, WhatsApp)?

[Your name]
```

## Personalization checklist (do this every time)
- [ ] Replaced [Name] and the goal read-back with THEIR words
- [ ] Swapped in the right demo/repo link
- [ ] Asked exactly ONE specific question
- [ ] Removed anything generic that could apply to any job
- [ ] Proposal is under ~8 lines
