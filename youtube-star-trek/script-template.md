# Episode Script Template

Copy this file for every new episode. It encodes a retention-optimized
structure. Fill the brackets. Target **8–14 minutes** (~1,300–2,200 spoken
words; people speak ~150 wpm).

> **The golden rule:** Every segment must either (a) pay off the hook or (b)
> raise a new question. The moment a viewer stops wondering "what's next," they
> leave.
