# Publishing Checklist

Copy this for every upload. Don't skip the packaging steps — they matter more
than the video itself for getting clicks.

## Before recording
- [ ] Topic chosen from `episode-ideas.md`
- [ ] Script written from `script-template.md`
- [ ] Read aloud once; boring lines cut
- [ ] Hook grabs in the first sentence

## Recording
- [ ] Quiet room, mic check (levels not clipping)
- [ ] Recorded in one energy-consistent take/session
- [ ] Saved a backup of the raw audio/footage

## Editing
- [ ] Dead air / "ums" trimmed
- [ ] B-roll on every visual cue (generated or licensed — no copyrighted clips
      as filler)
- [ ] Intro sting < 3 seconds
- [ ] Royalty-free music only, mixed low under voice
- [ ] On-screen text matches your brand style
- [ ] Captions added and cleaned up

## Packaging (the part that gets clicks)
- [ ] **Title** front-loads the keyword, uses a proven pattern
- [ ] **3 thumbnail variants** made; picked the highest-contrast/curiosity one
- [ ] Thumbnail readable on a phone, ≤3 words of text
- [ ] (Optional) Ran `virality_predictor` on hook/thumbnail
- [ ] **Description:** hook + keyword in first 2 lines, full summary below
- [ ] **Chapters/timestamps** added
- [ ] Added to the **"Stardate Files" playlist**
- [ ] End screen + cards point to a related video

## Upload settings
- [ ] Set to your fixed publish day/time (schedule, don't just dump)
- [ ] Visibility: Scheduled
- [ ] "Made for kids": almost certainly **No**
- [ ] Thumbnail uploaded (custom, not auto)

## After publishing
- [ ] Cut 1–2 **Shorts** from the video (use `reframe`/`personal_clipper`)
- [ ] Reply to **every** comment in the first 24–48h (huge for the algorithm)
- [ ] Note CTR + avg view duration after ~48h and ~7 days
- [ ] Log which topic/thumbnail style won so you can make more of it
