# 🖖 Star Trek YouTube Channel — Content Kit

Everything you need to launch and run an **episodic** Star Trek YouTube channel.
This kit is built around a repeatable series format so you can publish on a
schedule without reinventing the wheel each week.

## What's in here

| File | What it's for |
|------|---------------|
| [`channel-strategy.md`](channel-strategy.md) | Niche, audience, channel name ideas, positioning, growth plan, publishing cadence |
| [`episode-ideas.md`](episode-ideas.md) | A ready-to-shoot backlog of 30+ episode concepts with hooks and titles |
| [`script-template.md`](script-template.md) | The reusable skeleton every episode follows (hook → body → CTA) |
| [`episode-01-script.md`](episode-01-script.md) | A complete, ready-to-record first episode script |
| [`production-guide.md`](production-guide.md) | Gear, software, thumbnails, SEO, and the week-by-week workflow |
| [`tools-and-automation.md`](tools-and-automation.md) | The AI/automation tools wired into this workspace and how to use them |
| [`publishing-checklist.md`](publishing-checklist.md) | Copy-paste checklist for every upload |

## The core idea

**Pick one repeatable format and make it your "show."** New channels that grow
fastest aren't random — they have a recognizable episode structure viewers can
binge. This kit defaults to a flagship format called **"Stardate Files"** (you
can rename it), but the templates work for any angle.

## Start here

1. Read `channel-strategy.md` and lock your **channel name + format**.
2. Skim `episode-ideas.md` and pick your **first 5 episodes**.
3. Open `episode-01-script.md`, record it, edit it, ship it.
4. Use `publishing-checklist.md` for every upload.
5. Batch-record episodes 2–5 the same week so you're never scrambling.

## ⚠️ A note on copyright

Star Trek is owned by Paramount. Commentary, criticism, review, and education
are generally protected as **fair use** — but using long unedited clips, full
scenes, or background music from the shows is risky and can get videos
demonetized or struck. This kit is built around **commentary-first** formats
(your voice, your analysis, B-roll you create or license) to keep you safe.
See `production-guide.md` for specifics.
